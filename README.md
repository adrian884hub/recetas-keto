# 30 Keto Recipes: ebook sales landing page

Sales landing page for a digital recipe ebook ("30 Recetas Keto en 20 Minutos"), designed to turn visits into purchases. The page content is in Spanish, for the Argentine market.

**View the page:** https://adrian884hub.github.io/recetas-keto/

## What it includes

- Hero section focused on the reader's problem: eating keto without spending hours in the kitchen
- Benefits, the full list of the 30 recipes and a preview of the dishes
- A clear breakdown of what the buyer receives
- Frequently asked questions
- Repeated calls to action through the page

## Built with

- HTML, CSS and JavaScript in a single file, no libraries
- Published with GitHub Pages
